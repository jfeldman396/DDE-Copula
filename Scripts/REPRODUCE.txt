REPRODUCING THE REVISION AND SUPPLEMENT

Start in the repository root. Algorithms, Utilities, Scripts and Results
retain the original repository structure. Survey code and aggregate results
are included. Contact the author, Joe Feldman, for the original survey data.
Raw respondent data and manuscript/response/supplement .tex files are excluded.

1. QUICK START: ALL SAVED RESULTS, WITHOUT FITTING

  git clone --branch estimation-v2 https://github.com/jfeldman396/DDE-Copula.git
  cd DDE-Copula
  python3 -m venv .venv
  source .venv/bin/activate
  python -m pip install -r Scripts/Publication/requirements-render.txt
  python Scripts/reproduce.py --output-dir reproduced/revision

On Windows activate .venv\Scripts\activate instead. Use Python 3.11+ and a
NEW output directory. The runner validates hashes/counts, renders supported
saved numerical results, recomputes J=100 timings and exports exact artwork.
It starts no model fits. Open RESULT_INDEX.csv and REPRODUCTION_REPORT.json
in the destination for the per-result outputs and reproduction status.
The inventory covers 39 figure references and ten included table entries in the
author-designated v2 document snapshots. DOCUMENT_COVERAGE.json records their
hashes. The separate Reviewer1 variational-interval pilot is excluded at the
author's request; subsequent text/caption corrections remain in Overleaf.

Individual saved-result commands:
  python Scripts/Publication/validate_handoff.py
  python Scripts/Publication/render_native15_5.py --output reproduced/comparison
  python Scripts/Publication/reproduce_summary_results.py --output-dir reproduced/summaries
  python Scripts/Publication/render_factor_loadings.py --output-dir reproduced/factor
  python Scripts/Publication/render_ivae.py --output-dir reproduced/ivae
  python Scripts/Publication/export_document_figures.py --output-dir reproduced/artwork

These produce respectively: integrity checks; 12 shallow/comparator plots;
recovery/uncertainty/timing tables and three deep MSE plots; Gaussian/DDE
loadings; iVAE/DDE plots and key_items.json; and all preserved paper figures.
Preserved artwork is copied, not independently recalculated. No .tex is exported.

2. SOFTWARE AND OUTPUT LOCATIONS FOR FRESH FITS

MATLAB R2026a, Statistics and Machine Learning Toolbox, Optimization Toolbox,
a JVM and Parallel Computing Toolbox are used by the research scripts.
Comparators explicitly disable automatic parallel pools to preserve the
original serial random-number sequence. Start without an active pool.

Python analysis uses six packages: NumPy, pandas, SciPy, h5py, Matplotlib and
Pillow. PyTorch is needed only for iVAE training, in a separate environment:
  python -m pip install -r Scripts/Publication/requirements-ivae.txt
The many .m files are internal numerical functions, not separately installed
packages. Byte-identical helpers already in the original repo are reused.

Use NEW absolute paths below. OUT is a placeholder for an absolute directory
outside the checkout (for example /scratch/dde_revision). Each fitting command
refuses to overwrite its case directory. The full studies are expensive;
a shortened run is a diagnostic only. No fresh collector silently substitutes
saved publication values for missing fits. Completion does not imply mixing.

3. SHALLOW RECOVERY, COMPARATORS AND J=100 COMPUTE TIMES

In MATLAB, from this checkout:
  addpath('Scripts/Publication','Scripts/DDE');
  OUT='/absolute/new/revision_fits';
  run_revision_study('shallow',fullfile(OUT,'shallow'));
  run_revision_study('comparison',fullfile(OUT,'comparators'));

Shallow: J=[50 100 150], n=[500 1000 2000 4000 8000 16000],
replication=1:100, three arms; 5400 fits. MAP=tempering+VI, VI=VI only,
tempering=tempering only. Comparison adds 3600 RL/Poisson fits and reuses
the 1800 MAP endpoints from shallow. All inputs are regenerated with the
original data/algorithm seeds and native15/5 initialization; no external
paired-input archive is needed. Algorithms are not cropped from wider fits.

Then in the terminal (replace OUT with the same absolute directory):
  python Scripts/Publication/collect_revision_endpoints.py --study shallow --input-dir OUT/shallow --output-dir OUT/shallow_summary
  python Scripts/Publication/collect_revision_endpoints.py --study comparison --input-dir OUT --output-dir OUT/comparison_summary
  python Scripts/Publication/render_native15_5.py --data-dir OUT/comparison_summary --output OUT/comparison_figures

Outputs: DIMENSION_RECOVERY.csv; MSE_SUMMARY.csv; untrimmed per-replication
errors; retained/excluded IDs; average weight matrices; 12 MSE/loading PDFs.
Recovery columns K1_correct_pct, K2_correct_pct and both_correct_pct supply
the three-arm supplement tables. MAP MSE eligibility requires joint10/3
recovery; comparators use valid replications. Upper Q3+1.5 IQR trimming is
separate by method/J/n/layer, with exclusions retained. Poisson coefficients
are log-mean parameters, a different estimand from Gaussian latent loadings.

The collector also writes J100_MAP_RUNTIME_REPLICATES.csv and
J100_MAP_RUNTIME_SUMMARY.csv whenever all timing fields are present.
Numerical wall time=warmup+post-warmup, averaged over all100 MAP replications
per n, without MSE exclusions. Hardware, worker overhead and elapsed-time
measurements vary; identical new timings are not expected.

One complete case, for checking the installation:
  run_revision_case('shallow',50,500,1,'map','/absolute/new/one_map');
  run_revision_case('comparator',50,500,1,'rl','/absolute/new/one_rl');
  run_revision_case('comparator',50,500,1,'poisson','/absolute/new/one_poisson');
A partial-grid collector requires --preview and labels every output PREVIEW_.
Incomplete iteration-limited fits are rejected even in preview mode.

4. DEEP NO-FLOOR RECOVERY AND MSE

MATLAB:
  addpath('Scripts/Publication','Scripts/DDE');
  run_revision_study('deep','/absolute/new/deep');
Terminal:
  python Scripts/Publication/collect_revision_endpoints.py --study deep --input-dir /absolute/new/deep --output-dir /absolute/new/deep_summary

This generates J=108 inputs, fits all six n values and100 replications,
scores all three layers, and records initialization failures. Output includes
DIMENSION_RECOVERY.csv, MSE_SUMMARY.csv and B1_MSE.pdf/B2_MSE.pdf/B3_MSE.pdf.
Recovery counts all600 attempts. The n=500/r=76 zero-width initialization
failure is retained; never replace it with a modified initialization.
Published references contain599 fits plus this one failure. MSE uses joint
18/6/2 recovery and separate upper-IQR trimming by n/layer. Threshold is
3*n^(-.3) without a floor; the cap is160. Scoring includes intercepts,
alignment, width padding and each replication's truth/estimated Z scaling.

5. ORDINAL SYNTHETIC EXAMPLES AND TAIL PROBABILITIES

MATLAB:
  addpath('Scripts/Publication');
  run_revision_study('ordinal','/absolute/new/ordinal');
Terminal:
  python Scripts/Publication/collect_ordinal.py --input-dir /absolute/new/ordinal --output-dir /absolute/new/ordinal_summary

Eight models: Clayton, survival Clayton, Student t and Gaussian, each with
rank Gibbs and group maxima. Original n=1000 training counts and2000 test
counts are generated afresh; each model generates5000 synthetic observations.
The reported selected hyperparameters/seeds are frozen in config/ordinal.json.
To independently recreate their selection, including discarded candidates:
  run_ordinal_selection('/absolute/new/ordinal_selection');
This regenerates the original700/300 split, both two/three-layer grids,
beta refinements, finalist reranking and architecture-based reselection.
It verifies that all four selected settings match the reported settings.
The final refits also retain all five held-out pMSE replicates. Fixed categories are0-1,2-3,4-5,6-7,8+. They are a descriptive
projection after fitting count models, not a new ordinal estimator.

Outputs: ordinal_tail_probabilities.csv (96rows), ordinal_joint_examples.csv
(300rows), R1_2_ordinal_tail_probabilities.pdf and
R1_2_ordinal_synthetic_examples.pdf. All435 variable pairs enter tail averages;
they are not independent replications. Joint examples use variables1 and2.
The saved document filenames are ordinal_tail_probabilities.pdf and
ordinal_synthetic_vs_truth.pdf; exact historic artwork remains in Results.

6. SYNTHETIC UNCERTAINTY, ENCLOSURE AND MIXING DIAGNOSTICS

MATLAB:
  addpath('Scripts/Publication');
  run_revision_study('uncertainty','/absolute/new/uncertainty');
Terminal:
  python Scripts/Publication/collect_uncertainty.py --datasets-dir /absolute/new/uncertainty --chains-dir /absolute/new/uncertainty --output-dir /absolute/new/uncertainty_summary

Forty datasets: J=50/100, n=1000/2000, replication1:10. Each regenerates
the original maximal-width input and the50-step MAP initialization, then
runs four chains of2000 sweeps, discarding1000. This initializer differs
from the revised15/5 shallow experiment; its minimal legacy numerical
closure is retained in Algorithms/PosteriorGibbs/initialization for this reason.

Outputs: COVERAGE_SUMMARY.csv, DATASET_DIAGNOSTICS.csv, active-dimension
probabilities and per-dataset summaries. The collector standardizes draws,
applies the original fixed chain-mean alignment and computes rank/folded
split Rhat, bulk/tail ESS, retained-half checks and interval enclosure.
All40 reference datasets failed the mixing screen. Report enclosure, not
calibrated coverage; the between-dataset MC SE is not an MCMC error estimate.
--limit is only for a clearly provisional subset. Missing/short chains cannot
produce a complete-study claim. No preexisting MAP states/chains are required.

7. SURVEY PREPARATION, EMPIRICAL DDE AND GAUSSIAN COMPARISON

Contact Joe Feldman for the original CSV; do not commit it. Both its hash
and the prepared Y/X values are checked. The exact original column order
and the ideo5 column are required.

  python Scripts/Publication/prepare_survey.py --data /absolute/survey.csv --output-dir /absolute/new/survey

This writes train_input.mat with1500x98 Y (223 missing responses) and X
(missing replaced by3 for pMSE). Empirical DDE fitting retains missingness.
iVAE separately uses item-mean imputation. Ideology is used only for the
DDE descriptive plot, but is an auxiliary training variable for iVAE.

MATLAB, selected empirical model and complete Gaussian candidate study:
  addpath('Scripts/Publication');
  run_empirical_case('/absolute/new/survey/train_input.mat','maxima',9,'/absolute/new/dde_selected');
  run_gaussian_study('/absolute/new/survey/train_input.mat','/absolute/new/gaussian');

The DDE selection is the author's frozen choice: maxima config9 in the12/4
concentration grid, third-ranked10/1 fit, not the minimum-pMSE model.
The script performs full fitting and50 pMSE replicates. Expected endpoint:
740iterations, MODEL_it0740_target0800.mat. It saves the full12/4 checkpoint
as well as the selected10/1 model. To rerun the full selection grid, call
run_empirical_case for sampler={'gibbs','maxima'} and index=0:11, each in a
new directory. All24 settings/seeds are in config/empirical.json.

Gaussian runs all six candidates through4000+4000 iterations per chain,
with50 pMSE replicates each. Select by mean pMSE; the reference winner is c6.
Its poor invariant-correlation mixing remains a limitation. Fixed budgets
are not convergence diagnostics. Gaussian outputs are under stage8k/c1...c6.

Terminal, derive the full-sample empirical summaries and figures:
  python Scripts/Publication/collect_empirical.py --model /absolute/new/dde_selected/fit/MODEL_it0740_target0800.mat --data /absolute/survey.csv --dde-scores /absolute/new/dde_selected/PMSE_REPLICATES.csv --gaussian-dir /absolute/new/gaussian/stage8k --output-dir /absolute/new/empirical_summary
  python Scripts/Publication/render_factor_loadings.py --loadings /absolute/new/empirical_summary/all_standardized_loadings.csv --output-dir /absolute/new/factor_figure

Outputs:50 paired pMSE scores; positive-contrast anchors; higher-order profile
values/figures; A1_IDEOLOGY.pdf and group means; NORMALIZED_POINT.npz;
all_standardized_loadings.csv; Gaussian selection table; loading comparison.
HIGHER_ORDER_TOP_ANCHORS.pdf supplies the one-anchor-per-factor figure
called higher_level_profiles.pdf in the documents. A1_IDEOLOGY.pdf supplies
B5_10_1_ideology.pdf. Layout/font differences may occur across environments.

Normalization matters: profile/key-item/uncertainty calculations use beta/sd(Z),
leaving binary factors0/1. The supplied factor/iVAE comparison figure uses
beta*sd(A)/sd(Z). Both are reconstructed separately, matching the saved values.
Observed profile means omit missing responses and use exact model-based
posterior membership; these are descriptive, not heldout validation.
Local analysis outputs contain respondent posteriors; keep them private.

8. iVAE FIT, FIGURES AND KEY-ITEM TABLES

Use the separate PyTorch environment described in section2:
  python Algorithms/iVAE/train.py --train --data /absolute/survey.csv --output-dir /absolute/new/ivae_fit
  python Scripts/Publication/render_ivae.py --weights-dir /absolute/new/ivae_fit --dde-normalized /absolute/new/empirical_summary/NORMALIZED_POINT.npz --loadings /absolute/new/empirical_summary/all_standardized_loadings.csv --output-dir /absolute/new/ivae_figures

The ten columns are hidden units; latent dimension is one. Training uses
seed0,2000 iterations, batch256 and the original Gaussian-broadcasting patch.
Saved outputs are encoder/decoder weights, biases and loss; no respondent
embeddings are exported by train.py. Version/hardware differences may affect
training numerics. The renderer exports all four panels, row/unit matches
and key_items.json for all30 supplement table rows. Tables retain original
factor/unit order; figure matching permutes iVAE units without sign flips.
These methods use unequal information because iVAE also sees ideology.

The displayed window uses sweeps1001-2000, replacement seed35931531 for
chain1 and original seeds for chains2-4; longer unused windows need not run.
Condition on CSP active counts10/1, align each draw and propagate binary

10. VALIDATION AND REMAINING LIMITS

Algorithms and existing original files were retained; duplicate helpers are
reused. The single integrity manifest is Results/Publication/MANIFEST.json.
Validation evidence is in Results/Publication/REPRODUCTION_CHECKS.json.
Executable MATLAB checks and analysis parity checks are distinguished there
from studies that have not been rerun in full. Do not infer whole-study
validation from a representative exact fit or from saved-result rendering.

All statistical result families above now have explicit input-generation,
fitting and analysis routes. Survey replication requires author-provided data;
there is no public raw-data download bundled here. The full multi-thousand-fit
simulation grid, full Gaussian study and all posterior chains were not
rerun for the original packaging. The fresh iVAE run has reproduced all
network weights and its loss history. Consult the dated validation record
for the status of the subsequent complete-study verification. The portable ordinal selection driver reconstructs the discarded search,
while the direct refit driver uses the selected settings. Timings and stochastic results may
vary with numerical libraries/hardware. Existing poor-mixing caveats remain.

Introductory schematic artwork (MargY, Marg_Z, biv_Y, spec_clust) and exact
legacy typography are preserved assets. The six numerical truth heatmaps
are also regenerated by reproduce_summary_results.py; ordinal collection
now produces the two-column paper panels plus three-method audit panels. Synthetic truth arrays
are included as model specifications. Their exact artwork generators are not
required to estimate the revision/supplement results; obtaining identical
original artwork uses section1's exporter. No manuscript text is changed.


11. COMPLETE FRESH-RUN VERIFICATION (EXPENSIVE)

Use a fresh clone, install requirements-ivae.txt, and obtain the exact survey
CSV from the author. Keep the computer available until the workers finish.
The fitting runner uses9678 cases:9600 synthetic fits,40 four-chain posterior
datasets,24 empirical grid fits,one Gaussian study,one B5 fit/chain study,
four ordinal searches and eight ordinal final refits. iVAE runs separately.
There is no VI interval pilot in this scope. MATLAB workers use independent
random streams fixed by the original per-case seeds, and preserve failures.

  python Algorithms/iVAE/train.py --train --data /absolute/survey.csv --output-dir /absolute/new/ivae
  python Scripts/Publication/verify_from_scratch.py --survey-data /absolute/survey.csv --output-dir /absolute/new/full_verification --workers 4 --matlab /absolute/path/to/matlab
  python Scripts/Publication/check_reproduction.py --run-dir /absolute/new/full_verification --ivae-dir /absolute/new/ivae --survey-data /absolute/survey.csv --output-dir /absolute/new/numerical_comparison

--plan-only prepares a plan without starting MATLAB. --studies can select
ordinal_selection, ordinal, gaussian, b5, empirical, uncertainty, shallow,
comparison or deep. Separate disjoint runs can be supplied together after
--run-dir to the final checker. All components must be present for a pass.

PLAN.json records every case and source hashes. status/ and logs/ record
per-case progress. EXECUTION_REPORT.json records full-budget completion;
it does not claim numerical parity. The separate comparison REPORT.json
requires all included studies and compares newly computed tables, individual
replication errors, exclusions, matrix arrays, scores and posterior summaries.
Numerical tolerances are relative1e-10 and absolute1e-12. New wall times are
measured and reported rather than compared with historical hardware timings.
Pending cases and numerical mismatches prevent an overall pass.

A stopped controller can use --resume only with unchanged sources and the
same study list. Failed/interrupted cases require diagnosis; no files are
silently overwritten, no seeds changed, and no saved-fit fallback is used.

The original survey CSV merges missing-response codes. The main-text response
counts are reproduced as five observed categories plus missingness; the CSV
alone cannot recover a skipped-versus-not-asked distinction.
