# DDE-Copula: revision and supplement reproduction

**Start with [Scripts/REPRODUCE.txt](Scripts/REPRODUCE.txt)** for exact commands, required inputs, output filenames and validation limits.

To reproduce the packaged saved-result figures and tables:

```sh
python -m pip install -r Scripts/Publication/requirements-render.txt
python Scripts/reproduce.py --output-dir reproduced/revision
```

For fresh estimation, the guide covers shallow dimension recovery, RL/Poisson comparisons, deep no-floor simulations, ordinal examples, synthetic uncertainty, empirical DDE/Gaussian/iVAE fits, and B5 posterior figures. Synthetic inputs are generated by the scripts. **Contact the author, Joe Feldman, for the original survey data.** Survey-analysis code and aggregate results remain included.

The original structure is retained:

- `Algorithms/`: estimation kernels, comparators, posterior sampling and exact empirical prediction.
- `Utilities/`: shared numerical helpers, including unchanged original functions.
- `Scripts/`: complete-study and one-case runners, analysis, rendering and instructions.
- `Results/Publication/`: compact numerical references, figures, mappings and validation evidence.

The baseline is commit `424427fe1bf06d06494172cf278deb7bd4b29463`. Its 46 files remain, with only additive rules in `.gitignore`. No manuscript sources, raw respondent data, full chains or model checkpoints are published.

Most source files are MATLAB functions, not external packages. Python rendering/analysis uses six libraries; PyTorch is required only for iVAE training. Duplicate numerical helpers are reused. Related candidate records, uncertainty datasets and saved network weights are consolidated into three JSON files.

The additional empirical, ordinal and uncertainty-initialization functions are necessary to regenerate results that previously had only saved outputs or partial interfaces. The uncertainty study uses its own original 50-step MAP initializer; it cannot be replaced by the revised shallow estimator. Numerical kernels retain their separate functions so their behavior can be checked against the original studies.

Representative complete fits and aggregate analyses were checked against the research outputs. See [REPRODUCTION_CHECKS.json](Results/Publication/REPRODUCTION_CHECKS.json) for the exact checks. The entire multi-thousand-fit study has not been rerun for packaging. Gaussian/posterior mixing limitations remain; completing a fixed budget is not convergence. Ordinal refits use the reported selected settings. Original schematic artwork is preserved separately from computed statistical results.
